# Python Portfolio Projects

Welcome!! This repository is a collection of my Python-based data analysis projects, where I use Pandas, Matplotlib, and Seaborn to clean real-world datasets and uncover actionable insights through visualization.

## Projects

### [Data Job Market Analysis](Projects/Data_Job_Market_Analysis_Project)
An analysis of the data analyst job market: exploring the most in-demand skills, salary trends, and where high demand meets high pay. Includes skill-demand breakdowns by role, year-long trend analysis, salary distribution boxplots, and a scatter plot identifying the most "optimal" skills to learn.

**Tools:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

### [London Bike Rides Analysis](Projects/London_Bike_Project)
A data cleaning and exploratory analysis of 17,000+ London bike-share records, examining how weather, temperature, and time of day/week influence ridership patterns.

**Tools:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook, Tableau
